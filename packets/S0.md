# Packet S0 — "blank → alive": one harvester visibly moving

**Read `PROGRESS.md` and `BUILD_CONSTITUTION.md` first.** Do only this slice.

## Goal (the only thing that counts)
The deployed page renders the map and **one harvester that visibly moves**, every frame, driven by the sim
loop — and the **S0 liveness gate is green against the deployed bundle**. Nothing more. No economy, no
selection, no combat. Just: it's alive.

## What to build
1. **`src/sim/systems/movement.ts`** — a `SimSystem` named `'movement'`. For each entity with a
   `movement` + `position` component, step its `position` toward `movement.target` by `movement.speed`
   world-units this tick (clamp to the target). This is the *minimal* mover that makes S0 alive; the real
   harvester FSM is S1. It reads `state` only; it does NOT construct anything (lint will stop you).
2. **`src/view/`** — a canvas renderer: clear, draw the terrain tiles (read `state.grid` over its width/height,
   color by `terrainAt`), draw each entity as a placeholder shape at `worldToScreen(prev→current interpolated)`.
   A `Camera`. An rAF loop that: computes `dt` from wall-clock (this is `src/view`, wall-clock is allowed
   HERE), calls `accumulate()`, runs that many `runTick(state, systems)`, and draws every frame using the
   `remainderMs/STEP_MS` as interpolation alpha over `state.prevPositions`.
3. **`src/main.ts`** — bootstrap: `makeSimState({ seed, mapWidth, mapHeight })`; create one **refinery** entity
   (static) and one **harvester** entity with a `movement.target` a few tiles away (so it moves); register
   `[movement]` via `orderSystems`; start the renderer. Expose dev hooks the liveness test needs:
   `window.__debugHarvesterScreenPos()` reading the SAME renderer transform (locator, not truth).
4. **`tests/liveness/s0.spec.ts`** (Playwright, against `vite build && vite preview`): asserts a canvas exists,
   `getContext` was used, **non-background pixels > 5%**, and the harvester's **screen position at t≈1s differs
   from t≈3s** (it moved) — backed by a saved screenshot. Wire `playwright.config.ts` to build+preview.
